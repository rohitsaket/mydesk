# MASTER PROMPT — CORPORATE EMPLOYEE DESK / MY DESK HRMS WEBSITE

You are a senior enterprise software architect, product designer, UI/UX engineer, full-stack developer, database architect, security engineer, QA engineer, DevOps engineer, and HR technology specialist.

Your task is to design and build a complete, production-ready, enterprise-grade **Corporate Employee Desk / My Desk HRMS web application**.

This must not be a basic attendance dashboard.

It must become the employee’s complete daily workplace operating system where an employee can manage:

* Attendance
* Check-in / Check-out
* Live working hours
* Breaks
* Shift
* Overtime
* Attendance regularization
* Leave
* WFH
* On-duty requests
* Tasks
* Calendar
* Meetings
* Timesheets
* Payroll
* Payslips
* Expenses
* Reimbursements
* Documents
* HR requests
* Announcements
* Notifications
* Approvals
* Employee profile
* Team information
* Goals
* Performance
* Help desk
* Company directory
* Holidays
* Birthday/work anniversary information
* Personal productivity
* Employee self-service

The application should feel like a combination of:

* Microsoft 365 employee portal
* Workday
* Darwinbox
* Zoho People
* SAP SuccessFactors
* Rippling
* BambooHR
* Slack-style workplace productivity
* Modern enterprise SaaS dashboard

Do not copy any product directly.

Create an original, clean, professional, premium enterprise UI.

# 9. ATTENDANCE CALCULATION ENGINE

Track:

```text
scheduled_duration
gross_work_duration
net_work_duration
break_duration
paid_break_duration
unpaid_break_duration
late_duration
early_exit_duration
overtime_duration
productive_duration
```

Formula example:

```text
gross duration =
last activity - first check-in

net work =
gross duration - unpaid breaks

remaining =
required work duration - net work
```

Never calculate payroll-sensitive totals only in the frontend.

Backend remains authoritative.
